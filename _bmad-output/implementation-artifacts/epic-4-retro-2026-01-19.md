## Challenges & Growth Areas

### Story 4.3 Complexity

Raw JSONL Mode had the most code review issues (5 HIGH/MEDIUM):

| Issue | Severity | Resolution |
|-------|----------|------------|
| `formatJSONLine()` only handled objects, not arrays | MEDIUM | Changed to `json.Indent()` with `bytes.Buffer` |
| Lazy loading broken in raw mode (used entries count) | HIGH | Added `loadMoreRawLines()` method |
| Raw mode scroll check used wrong count | HIGH | Updated to check `rawLineCount` when `rawMode` true |
| Navigation to unloaded line was silent no-op | HIGH | Load all content when target > loadedCount |
| Missing tests for raw mode lazy loading | MEDIUM | Added 6 new tests |

### Key Lesson: Lazy Loading + New View Modes

New view modes (like raw JSONL) require mode-specific lazy loading consideration. The normal mode patterns don't translate directly - each feature needs raw-mode-specific handling.

**Reported by:** Jongkuk Lim (during retrospective discussion)

| Field | Detail |

| Location | `buildPositionSegment()` in `viewer.go` |
