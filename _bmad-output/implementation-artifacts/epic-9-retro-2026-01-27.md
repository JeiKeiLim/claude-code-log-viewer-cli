**Critical Issue (H1):** Story 9.2's polling chain would break after processing an event - the handler wasn't scheduling the next tick. This would cause the dashboard to receive ONE event, then stop updating entirely. Fixed by using `tea.Batch()` to return both the event command and the next tick command.
