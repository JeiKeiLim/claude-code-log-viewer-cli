## Significant Discovery

### Gap: Interactive Browse-then-Watch

**User Expectation:**
1. Start `cclv` in interactive mode (no arguments)
2. Browse projects -> select conversation
3. Enable watch mode on selected conversation

**Current Reality:**
- Must know file path upfront
- `--watch` flag requires file argument
- No way to enable watching after browsing to a conversation

**Resolution:**
- **Story 2.4 created** - Enable Watch Mode from Interactive Browse
- Adds 'w' key shortcut in conversation list and viewer
- Allows toggling watch mode on/off dynamically
